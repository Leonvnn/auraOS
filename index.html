04 — RF / IR scope
Useful lab tools without interference.
AuraOS can still have a proper RF-lab menu. The generated radio features focus on observing and testing your own hardware rather than disrupting other devices.




CC1101 SpectrumRSSI sweep around a selected sub-GHz center frequency, module status and receive monitor.


nRF24 Activity2.4 GHz channel activity sweep using RPD, channel monitor and module diagnostics.


IR toolsIR receive monitor, last decoded value and optional NEC transmit from the WebUI.
