03 — Tutorial
What the RF menu contains.




RF Tools → CC1101


Scan / Copy searches around the selected sub-GHz range, then captures a short ASK/OOK raw waveform. Spectrum sweeps the selected range. RSSI Spectrum continuously samples RSSI and scrolls the graph left.


RF Tools → nRF24


Channel Scan measures RPD activity across channels 0–125. Capture / Copy uses the known Aura test pipe (AURA1) on the selected channel. RPD Spectrum continuously scrolls channel activity on screen and in the WebUI.


Install libraries for the features you enable: U8g2, RadioLib, RF24 by TMRh20 and IRremoteESP8266.
