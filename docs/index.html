01 — Builder

Configure the device.

The builder checks required interfaces and GPIO availability before it generates code. If a setting cannot be changed, AuraOS tells you why instead of silently ignoring it.

04 — Hardware support
One builder, multiple boards.
Official Espressif profiles are separated from community/generic profiles so the site does not pretend every ESP32 board has the same physical pinout.

  

    
C3
ESP32-C3
Small, efficient builds. Great for AOB/AOH and lighter radio combinations.
  • SuperMini Plus
  • DevKitM-1
  • DevKitC-02
  • Pro Mini (Beta)

    
S3
ESP32-S3
More GPIO headroom, making OLED + IR + multiple SPI modules much easier.
  • DevKitC-1
  • Generic S3 (Beta)

    
C5
ESP32-C5
AuraOS v1 includes a C5 profile, marked Beta while the newer board/library ecosystem matures.
  • DevKitC-1
  • Generic C5 (Beta)

  

  
Beta/community board profiles can reserve different GPIOs depending on revision. Always compare the generated pinout with the exact board you own.
